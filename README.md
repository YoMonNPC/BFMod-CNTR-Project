## ⚠️ 风险告知

致本项目的用户：

&emsp;&emsp;BlockFront（简称 BFMod 或 BF）是由 BoehMod / LeScooter 开发的一款二战题材 Minecraft 模组，目前暂无官方中文译名，简体中文社区常用译名为“方块前线”，下文亦沿用该译名。

&emsp;&emsp;本项目的初衷是方便中文用户游玩此模组。自 2023 年以来，截至本文撰写之日，本项目在各渠道的累计下载量已超过 11,000 次，由衷感谢各位的支持。但遗憾的是，近期出现了一些值得关注的情况：多名使用本项目且实力较强的玩家遭到《方块前线》官方管理组封禁；同时，也有玩家因在游戏内反击针对中文用户的歧视性言论，先被管理组禁言，随后又被追加云端永久封禁。由于《方块前线》允许管理员对用户游戏进行屏幕截图并检查，结合以上封禁实例，项目维护者及部分简体中文玩家合理怀疑该模组的管理组存在对中文用户的针对性对待。

&emsp;&emsp;此外，《方块前线》的隐私政策表明，该模组会收集用户的硬件信息以实施“硬件封禁”，禁止用户通过更换账号或设备来逃避封禁。这一手段虽能威慑作弊行为，但《方块前线》并未配备与之匹配的自动且高效的反作弊系统，封禁基本依赖玩家举报与人工审核，主观性极强；账号封禁后即刻解除与 Discord 的关联，失去访问频道的权限，意味着仅凭个人完全无法对封禁进行申诉。尽管《方块前线》是免费模组，采用 Microsoft 账号认证，除赞助外官方不直接从中获利，但项目维护者依然认为该模组当前的管理方式存在上述不合理之处。

&emsp;&emsp;以上内容同样包含个人的主观判断。鉴于项目维护者暂无与繁体中文用户的沟通渠道，上述信息可能仅适用于简体中文社区。若您希望规避风险，请谨慎考虑是否继续使用本项目。若文中所述“针对性对待”的情况得到证实，本项目将考虑停止更新。

<br>

## ⭐ 项目功能

- 添加了：
  - 带自定义字体（[汉仪力量黑简][hyliliangheij]）的简体中文（中国大陆）翻译。
  - 带自定义字体（[MStiffHei HK][mstiffhei-hk]）的繁体中文（台湾 / 香港特别行政区）翻译。
- 修正了原文中的部分拼写、语法。
- 格式化了游戏内的中文。

[hyliliangheij]: https://www.hanyi.com.cn/productdetail.php?id=589
[mstiffhei-hk]: https://www.onlinewebfonts.com/download/

<br>

## 🛠️ 使用方法

本项目发布页：

| | |
| :- | :- |
| Modrinth | [简体中文][project-modrinth-schinese] \| [繁体中文][project-modrinth-tchinese] |
| GitHub | [简体中文 & 繁体中文][project-github] |

1. 下载资源包。
2. 将资源包放入游戏资源包文件夹（resourcepacks）。
3. 在游戏中启用资源包，并确保资源包处于“模组资源”（Mod Resources）上方。

[project-modrinth-schinese]: https://modrinth.com/resourcepack/bfmod-cntr-project-schinese
[project-modrinth-tchinese]: https://modrinth.com/resourcepack/bfmod-cntr-project-tchinese
[project-github]: https://github.com/YoMonNPC/BFMod-CNTR-Project

## ⚠️ 注意事项

- PCL II 用户请更新至 2.9.2 及以上版本并在版本设置中禁用 Java Launch Wrapper，否则将无法通过模组反作弊检测。
