## ⚠️ 風險告知 · Risk Notice

致本項目的使用者：

&emsp;&emsp;BlockFront（簡稱 BFMod 或 BF）是由 BoehMod / LeScooter 開發的一款二戰題材 Minecraft 模組，目前暫無官方中文譯名，簡體中文社群常用譯名為「方塊前線」，下文亦沿用該譯名。

&emsp;&emsp;本項目的初衷是方便中文使用者遊玩此模組。自 2023 年以來，截至本文撰寫之日，本項目在各渠道的累計下載量已超過 11,000 次，由衷感謝各位的支援。但遺憾的是，近期出現了一些值得關注的情況：多名使用本項目且實力較強的玩家遭到《方塊前線》官方管理組封鎖；同時，也有玩家因在遊戲內反擊針對中文使用者的歧視性言論，先被管理組禁言，隨後又被追加雲端永久封鎖。由於《方塊前線》允許管理員對使用者遊戲進行螢幕截圖並檢查，結合以上封鎖實例，項目維護者及部分簡體中文玩家合理懷疑該模組的管理組存在對中文使用者的針對性對待。

&emsp;&emsp;此外，《方塊前線》的隱私政策表明，該模組會收集使用者的硬體資訊以實施「硬體封鎖」，禁止使用者透過更換帳號或裝置來逃避封鎖。這一手段雖能威懾作弊行為，但《方塊前線》並未配備與之匹配的自動且高效的反作弊系統，封鎖基本依賴玩家檢舉與人工審核，主觀性極強；帳號封鎖後即刻解除與 Discord 的關聯，失去訪問頻道的權限，意味著僅憑個人完全無法對封鎖進行申訴。儘管《方塊前線》是免費模組，採用 Microsoft 帳號認證，除贊助外官方不直接從中獲利，但項目維護者依然認為該模組目前的管理方式存在上述不合理之處。

&emsp;&emsp;以上內容同樣包含個人的主觀判斷。鑑於項目維護者暫無與繁體中文使用者的溝通渠道，上述資訊可能僅適用於簡體中文社群。若您希望規避風險，請謹慎考慮是否繼續使用本項目。若文中所述「針對性對待」的情況得到證實，本項目將考慮停止更新。

## ⭐ 專案功能

- 添加了：
  - 帶自訂字型（[漢儀力量黑簡][hyliliangheij]）的簡體中文（中國大陸）翻譯。
  - 帶自訂字型（[MStiffHei HK][mstiffhei-hk]）的繁體中文（台灣 / 香港特別行政區）翻譯。
- 修正了原文中的部分拼寫、語法。
- 格式化了遊戲內的中文。

[hyliliangheij]: https://www.hanyi.com.cn/productdetail.php?id=589
[mstiffhei-hk]: https://www.onlinewebfonts.com/download/

## 🛠️ 使用方法

本專案釋出頁：

| | |
| :- | :- |
| Modrinth | [簡體中文][project-modrinth-schinese] \| [繁體中文][project-modrinth-tchinese] |
| GitHub | [簡體中文 & 繁體中文][project-github] |

1. 下載資源包。
2. 將資源包放入遊戲資源包資料夾（resourcepacks）。
3. 在遊戲中啟用資源包，並確保資源包處於「模組資源」（Mod Resources）上方。

[project-modrinth-schinese]: https://modrinth.com/resourcepack/bfmod-cntr-project-schinese
[project-modrinth-tchinese]: https://modrinth.com/resourcepack/bfmod-cntr-project-tchinese
